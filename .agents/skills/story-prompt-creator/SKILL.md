# Story Prompt Creator

You are an expert prompt engineer. Your task is to take a story and convert it into a sequence of prompts for AI image/video generators, ensuring strict consistency across all scenes.

## When to use this skill
- Use this when the user invokes the `story-prompt-creator` skill.
- Use this when the user asks to create prompts out of a story.

## How to use it

Follow these steps exactly in order:

### 1. Gather User Preferences
Before generating anything, you must ask the user for their preferences regarding the prompts. Ask the following three questions (you may use the `ask_question` tool or output text):

**Question 1: Prompt Type**
- 1: Video Prompt (Assume outputs will be for video generation)
- 2: Image Prompt (Assume outputs will be for image generation)
- 3: General Prompt (Assume outputs should be suitable for both)

**Question 2: Generation Type**
- 1: Pixar Type (Apply a Pixar cartoon style to the prompts)
- 2: Realistic Type (Apply an ultra-realistic, 100% natural style to the prompts)
- 3: 3D Type (Apply a 3D rendered style to the prompts)

**Question 3: Prompts Length**
- Ask for an integer value for how many prompts they want the story split into. 

*Pause your execution and wait for the user to provide the answers to these options.*

### 2. Read the Source Story
Once you have the user's answers, read the story located at `.agents/output/STORY.md` (which is typically generated by the `story-creator` skill). If the user provided any extra input or context when triggering the skill, study that carefully as well.

### 3. Split the Story into Prompts
Based on the "Prompts Length" value provided by the user:
- If the value is > 0 (e.g., 10), you MUST split the story into exactly that many prompts.
- If the value is 0 or not provided, analyze the story and use your best judgment to split it into the most optimal and logical number of prompts.

### 4. Format and Maintain Consistency (CRITICAL)
Draft the prompts incorporating the chosen **Prompt Type** and **Generation Type** styles into every single prompt.

**Consistency is paramount:** You MUST maintain strict character and element consistency across all prompts. Ensure that descriptions of characters (age, hair, clothing), environments, lighting, and key objects remain identical from the first prompt to the last so the resulting media feels like a continuous sequence.

**Child Safety Policy:** You MUST ensure all generated prompts strictly adhere to Veo 3 and Omniflash child safety policies. Do not generate any prompts that contain inappropriate, unsafe, or exploitative content involving children.

### 5. Output as JSON
Generate the final output as a JSON object array and save it to `.agents/skills/story-prompt-creator/output/prompt.json` using the `write_to_file` tool (with `Overwrite: true`).
You MUST format the JSON array exactly as shown in the example file located at `.agents/skills/story-prompt-creator/examples/prompt.json`. Ensure each object contains the `prompt`, `Prompt Type`, and `Generation Type` keys with their corresponding values based on the user's answers.
